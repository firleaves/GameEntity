# 快速开始

## 1. 引用包

当前仓库中的包路径是：

```text
unity/Packages/com.firleaves.gameentity.unity.framework
```

程序集依赖 `GameEntity.Unity.Framework` 后，代码中引入：

```csharp
using Cysharp.Threading.Tasks;
using GameEntity.Unity.Framework;
```

如果业务使用 asmdef，需要在其 `references` 中加入 `GameEntity.Unity.Framework`。包本身还依赖 GameEntity Unity、UniTask、YooAsset 与 UGUI。

## 2. 场景启动

推荐在启动场景创建一个常驻 GameObject，并添加：

- `FrameworkEntry`：创建并持有框架服务。
- `GameLauncher`：等待框架就绪后，按顺序运行所有 `IGameLaunchTask`。

`FrameworkEntry` 默认在 `Awake` 自动初始化，执行顺序为 `-9000`；`GameLauncher` 默认在 `Start` 启动，执行顺序为 `-8000`。如果场景没有 `GameEntityRunner`，两者都会按配置自动补充。

在 Inspector 中配置 `FrameworkEntry`：

- `Auto Initialize On Awake`：通常保持开启。
- `Options > Features`：只启用实际需要的服务。
- `Options > Yoo Asset`：配置包名与运行模式。
- `Options > Dont Destroy On Load`：启动入口是否跨场景保留。
- `Extensions`：可选的 `FrameworkExtensionAsset` 列表。

> 默认 `Features` 启用全部模块，也会初始化 YooAsset。只需 Timer/Event 等纯逻辑模块时，应裁剪 Features，避免引入不需要的资源初始化。

## 3. 等待初始化完成

最可靠的业务启动方式是实现 `IGameLaunchTask`，由 `GameLauncher` 调用：

```csharp
using System.Threading;
using Cysharp.Threading.Tasks;
using GameEntity.Unity.Framework;
using UnityEngine;

public sealed class BootstrapGameTask : MonoBehaviour, IGameLaunchTask
{
    public int Order => 100;

    public async UniTask LaunchAsync(
        FrameworkEntry framework,
        CancellationToken ct = default)
    {
        if (GameEntry.HasFeature(FrameworkFeatures.GameData))
        {
            await GameEntry.Data.LoadAllAsync(ct);
        }

        if (GameEntry.HasFeature(FrameworkFeatures.Procedure))
        {
            GameEntry.Procedure.Register<BootProcedure>();
            await GameEntry.Procedure.ChangeStateAsync<BootProcedure>();
        }
    }
}
```

任务先按 `Order` 升序排列；相同 `Order` 再按类型完整名称排序。不要依赖 Unity 返回组件的原始顺序。

不使用 `GameLauncher` 时，可以显式等待：

```csharp
await frameworkEntry.InitializeAsync(cancellationToken);
IEventBus eventBus = GameEntry.Event;
```

若要把自定义 `FrameworkOptions` 传给 `InitializeAsync(options, ct)`，必须先在 Inspector 关闭自动初始化，避免 `Awake` 中的默认初始化与手动初始化竞争。

## 4. 获取服务

内置服务有三种获取方式：

```csharp
// 必选模块：未就绪或未启用时抛 FrameworkException。
IAssetPool assets = GameEntry.Asset;

// 自定义扩展服务或按接口获取。
IMyService custom = GameEntry.Get<IMyService>();

// 可选能力探测：不会因为框架未就绪而抛异常。
if (GameEntry.TryGet<INetworkSystem>(out var network))
{
    // 使用 network。
}
```

强类型入口映射：

```text
Asset          -> IAssetPool
Data           -> IGameData
ResourceUpdate -> IResourceUpdateSystem
Scene          -> ISceneSystem
Instance       -> IInstancePool
Audio          -> IAudioSystem
Timer          -> ITimerSystem
Event          -> IEventBus
Localization   -> ILocalizationSystem
Settings       -> IGameSettings
UI             -> IUISystem
Save           -> ISaveSystem
Procedure      -> IProcedureSystem
Network        -> INetworkSystem
```

## 5. 最小纯逻辑配置

若仅需要计时器、事件、流程和存档，可关闭自动初始化后使用：

```csharp
var options = FrameworkOptions.CreateDefault();
options.Features = FrameworkFeatures.Timer
    | FrameworkFeatures.Event
    | FrameworkFeatures.Procedure
    | FrameworkFeatures.Save;

await frameworkEntry.InitializeAsync(options, cancellationToken);
```

该组合不需要 YooAsset。启用 Asset、ResourceUpdate 或 Scene 中任一模块时，Framework 会初始化 YooAsset。

## 6. 关闭

销毁 `FrameworkEntry` 会触发关闭；也可主动等待完整清理：

```csharp
await frameworkEntry.ShutdownAsync(cancellationToken);
```

关闭开始后 `GameEntry` 立即注销，业务代码不应再获取服务。所有自持有的资源句柄仍应在业务生命周期中提前释放。
