# 符号索引

本页供 AI 和开发者按类型名快速定位。从本页访问源码的相对目录是 `../Runtime`；下文路径均以包根目录下的 `Runtime` 为前缀。

## Core

- `FrameworkEntry`：Unity 初始化入口；`Runtime/Core/FrameworkEntry.cs`。
- `FrameworkScene`：服务容器和 GameEntity Scene；`Runtime/Core/FrameworkScene.cs`。
- `GameEntry`：静态服务门面；`Runtime/Core/GameEntry.cs`。
- `GameLauncher`：启动任务编排；`Runtime/Core/GameLauncher.cs`。
- `IGameLaunchTask`：可排序启动任务；`Runtime/Core/IGameLaunchTask.cs`。
- `FrameworkOptions`：总配置；`Runtime/Core/FrameworkOptions.cs`。
- `FrameworkFeatures`：模块 Flags；`Runtime/Core/FrameworkFeatures.cs`。
- `FrameworkExtensionAsset` / `FrameworkExtensionContext`：扩展注册；`Runtime/Core`。
- `FrameworkException`：框架配置和状态异常；`Runtime/Core/FrameworkException.cs`。

## Asset 与资源链路

- `IAssetPool`：资源加载、预加载、释放与快照；`Runtime/Asset/IAssetPool.cs`。
- `AssetKey`：资源身份；`Runtime/Asset/AssetKey.cs`。
- `AssetRef<T>` / `SubAssetsRef<T>` / `RawFileRef`：资源所有权句柄；`Runtime/Asset`。
- `AssetLoadOptions` / `AssetPreloadOptions`：加载与预加载配置；`Runtime/Asset`。
- `IYooAssetBootstrap` / `YooAssetBootstrap`：YooAsset 包初始化；`Runtime/Asset`。
- `IResourceUpdateSystem` / `ResourceDownloader`：清单与下载；`Runtime/ResourceUpdate`。
- `ISceneSystem` / `SceneRef` / `SceneLoadOptions`：Unity 场景加载；`Runtime/Scene`。

## 实例与表现

- `IInstancePool` / `InstanceRef`：GameObject 租用与归还；`Runtime/Pooling`。
- `PoolPolicy`：实例池策略；`Runtime/Core/PoolPolicy.cs`。
- `IUISystem` / `UIEntity` / `UIOpenParams`：UI 管理；`Runtime/UI`。
- `IUIView` / `IUIAdapter` / `UGUIAdapter`：UI 视图适配；`Runtime/UI`。
- `IAudioSystem` / `AudioPlayHandle` / `AudioPlayOptions`：音频；`Runtime/Audio`。
- `ILocalizationSystem` / `LocalizationTable`：本地化；`Runtime/Localization`。
- `IGameSettings` / `GameSettings`：玩家设置；`Runtime/Settings`。

## 游戏逻辑

- `ITimerSystem` / `TimerHandle`：延迟和重复计时；`Runtime/Timer`。
- `IEventBus` / `EventBusOptions`：同步与排队事件；`Runtime/Event`。
- `IGameData` / `IDataTable<T>`：静态数据表；`Runtime/Data`。
- `ISaveSystem` / `ISaveStorage`：存档与存储边界；`Runtime/Save`。
- `IProcedureSystem` / `IProcedure` / `Procedure`：异步流程状态机；`Runtime/Procedure`。
- `INetworkSystem` / `INetworkChannel`：网络系统和频道；`Runtime/Network`。
- `INetworkProtocol` / `JsonNetworkProtocol`：编解码协议；`Runtime/Network/Protocol`。
- `INetworkTransport` / `TcpNetworkTransport` / `MockNetworkTransport`：传输层；`Runtime/Network/Transport`。

## 按动作查 API

- 加载 Unity 资源：`IAssetPool.LoadAsync<T>`。
- 加载原生文件：`IAssetPool.LoadRawFileAsync`。
- 预加载：`IAssetPool.PreloadAsync` / `PreloadGroupAsync`。
- 创建 prefab 实例：`IInstancePool.RentAsync`。
- 打开界面：`IUISystem.OpenAsync<TUI>`。
- 切换 Unity 场景：`ISceneSystem.ChangeSceneAsync`。
- 播放音效：`IAudioSystem.PlaySfxAsync`。
- 延迟执行：`ITimerSystem.Delay`。
- 同步发事件：`IEventBus.Publish`。
- 下一更新阶段发事件：`IEventBus.Post`。
- 读取配置：`IGameData.Get<T>` / `TryGet<T>`。
- 写入存档：`ISaveSystem.Save<T>`。
- 切换游戏流程：`IProcedureSystem.ChangeStateAsync`。
- 网络请求响应：`INetworkChannel.CallAsync<TRequest,TResponse>`。
- 获取自定义扩展：`GameEntry.Get<T>` / `TryGet<T>`。
